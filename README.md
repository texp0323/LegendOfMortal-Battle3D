# Battle3D — 활협전 단체전 3D 모드

**활협전(Legend of Mortal)** 의 단체전을 새로 제작한 3D 전투로 전환하는 BepInEx 모드입니다.
원본 전투 씬은 인원·수치·규칙·UI·소리 등 데이터를 읽는 용도로만 사용하며, 3D 월드는 모두 새로 생성합니다. 지정되지 않은 전투는 원본 그대로 진행됩니다.

## 모드 소개
활협전의 단체전을 새로 제작한 3D 전투로 바꿔 주는 모드입니다. 주인공 조활을 직접 조작해 싸우며, 유닛과 수치, 규칙은 원본 데이터를 그대로 따릅니다.

## 설치 (모드 베이스를 이미 설치하셨다면 1, 2번은 건너뛰십시오)

**최신 릴리즈: [v0.1.15](https://github.com/texp0323/LegendOfMortal-Battle3D/releases/latest)** · **[Battle3D_v0.1.15.zip 다운로드](https://github.com/texp0323/LegendOfMortal-Battle3D/releases/download/v0.1.15/Battle3D_v0.1.15.zip)** (약 120 MB)

1. **BepInEx 6** (Unity Mono, `6.0.0-be.692`)를 내려받아 게임 폴더(`Mortal.exe`가 있는 폴더)에 압축 해제합니다.
   - [BepInEx 빌드 페이지](https://builds.bepinex.dev/projects/bepinex_be)에서 `be.692` 의 *Unity Mono, Windows x64* 를 내려받습니다.
2. 게임을 한 번 실행하여 `BepInEx` 폴더가 생성된 것을 확인한 뒤 종료합니다.
3. 위의 **Battle3D_v0.1.15.zip 다운로드** 링크로 설치 파일을 내려받습니다. [최신 릴리즈 페이지](https://github.com/texp0323/LegendOfMortal-Battle3D/releases/latest)에서는 **Assets → `Battle3D_v0.1.15.zip`**을 선택하십시오. `Source code (zip)`과 `Source code (tar.gz)`는 설치 파일이 아닙니다.
4. 내려받은 ZIP의 압축을 풀고, 안의 `BepInEx` 폴더를 **게임 폴더에 그대로 붙여넣기(덮어쓰기)** 합니다.
   결과: `...\LegendOfMortal\BepInEx\plugins\Battle3D\Battle3D.dll`
5. 게임을 실행하고 단체전에 진입하면 3D 전투가 시작됩니다.

제거하려면 `BepInEx\plugins\Battle3D` 폴더를 삭제하십시오. 설정은 `BepInEx\config\mortal.battle3d.cfg`에 저장되며, 이 파일은 삭제해도 무방합니다.

**게임패드**

조작 방식을 **Keyboard**로 두면 게임패드도 함께 쓸 수 있습니다(키보드와 동시에 사용 가능). 다른 방식에서는 게임패드가 동작하지 않습니다. 버튼 이름은 Xbox 기준이며, PlayStation은 같은 위치의 □ ○ × △, L1 R1 L2 R2입니다.

| 동작 | 버튼 |
|---|---|
| 이동 | 왼쪽 스틱 / 방향 패드 |
| 공격 (3연격) | X |
| 암기 | B (길게 누르면 포물선 포사) |
| 구르기 / 대시 | A |
| 구공 | Y |
| 스킬 1~4 | LB RB LT RT |
| 자동 조준 켜기·끄기 | 오른쪽 스틱 누르기 |
| 일시정지 / 전투 시작 | Start (전투 시작은 A도 가능) |

원본 메뉴(스킬 선택 등)는 마우스·키보드로 조작합니다.

**공통**

- 자동 조준 켜기·끄기: 왼쪽 Ctrl
- 스킬을 키를 뗄 때 사용: F4 패널(또는 `[Controls] SkillRelease`)에서 켜면, 스킬 키를 누르는 동안 바닥에 사거리가 빨갛게 표시되고 키를 뗄 때 사용합니다. 끄면(기본) 누르는 즉시 사용합니다.
- 설정 패널: F4
- 조작 목록 숨기기: F11
- 마비가 걸리면 1초 동안 이동할 수 없습니다(공격과 행동은 가능). 이후에는 이동이 느려집니다.
- 조활이 던지는 암기(평사·곡사)의 피해는 항목 피해의 50%로 들어갑니다. 암기 효과가 쌓는 독·마비 누적치는 2배이며, 효과가 시작되기 전에는 줄어들지 않습니다.
- 구공: 주변 적이 조활을 노리며 쿨타임은 5초입니다. 배운 음공(용음공·호소공·열화선)은 자동으로 적용되고 하나당 쿨타임이 1초 늘어납니다. 용음공은 추가 피해, 호소공은 마비, 열화선은 화상을 더합니다.
- 도검 수치가 높을수록 평타가 빨라집니다(100에서 최대 +50%).
- 스킬 선택 화면: 목록 클릭으로 장착·해제, 드래그로 교체, 우클릭으로 해제. F4 패널에서 끌 수 있습니다.
- F4 패널의 "적 일괄 등장"을 켜면 적 전원이 처음부터 필드에 섭니다.

**경공에 따른 구르기·대시와 이동 속도**

- Space를 누르면 **경공 25 미만은 구르기**, **25 이상은 대시**를 사용합니다. 두 동작 모두 기력이 필요합니다.
- 경공에 따른 기본 이동 속도 배율은 **`1 + max(0, 경공) × 0.0005`**입니다. 경공 1당 0.05% 증가하며, 경공 25는 **1.0125배**, 50은 **1.025배**, 100은 **1.05배**입니다.
- 대시 최대 거리는 **`3 + (경공 - 25) × 0.06` m**입니다. 경공 25는 **3 m**, 50은 **4.5 m**, 100은 **7.5 m**입니다. 가까운 커서를 향하면 최대 거리보다 짧게 대시하며, 최소 거리는 1 m입니다.
- 구르기는 경공과 관계없이 기본 거리 **4.6 m**, 전체 동작 시간 **0.95초**입니다. 위 이동 속도 배율은 일반 이동에 적용됩니다.

<details>
<summary><b>조활의 스킬</b></summary>

- **분력일격**: 기본 공격보다 강한 연속 베기입니다. 기본 공격과 마찬가지로 연격이 쌓입니다.
- **호체기조**: 5초 동안 모든 피해와 상태이상을 받지 않는 방어막을 펼칩니다.
- **방어**: 정면의 적을 밀쳐 냅니다. 동작 중에는 피해를 받지 않습니다.
- **점파운관**: 연격이 8 이상일 때, 쌓인 연격을 모두 소모해 앞으로 찌르며 달려 나갑니다. 피해는 막타 피해 × 0.5 × 연격입니다.
- **운소뇌정벽력도**: 웅크려 기를 모은 뒤 평타 3타(강타)로 베며 앞 부채꼴에 벼락을 내려 피해와 마비를 주고 균형을 무너뜨립니다. 동여뢰진이 있으면 맞은 적이 넘어져 2초간 움직이지 못합니다.
- **풍뢰신각**: 연격이 4 이상일 때, 연격을 모두 소모해 날아차기로 앞을 가릅니다. 피해는 막타 피해 × 0.45 × 연격입니다.
- **비천각**: 점프 후 내려찍습니다.
- **번랑도법**: 앞을 베어 맞은 적을 밀치고, 그중 가장 가까운 적의 머리 위에 파란 불꽃 표식을 남긴 뒤 그 앞으로 돌진해 한 번 더 벱니다.
- **철비비권**: 앞의 넓은 길목(길이 5 m, 폭 3.4 m)을 쳐서 막타 피해 × 1.5를 주고, 맞은 적을 뒤로 밀어내 2초 동안 쓰러뜨립니다. 슈퍼아머 적은 피해만 받습니다(최대 20명).
- **연환비표** · **삼화제방** · **점수비석** (슬롯 패시브 스킬): 눌러서 쓰는 스킬이 아니라, 슬롯에 장착해 두면 효과가 적용됩니다.
  - 연환비표: 암기 키를 누르고 있으면 연속 발사합니다(곡사 불가). 간격은 암기 수치 0에서 0.6초, 100에서 0.15초입니다.
  - 삼화제방: 곡사로 던질 때 암기가 2발 더 나갑니다. 연환비표와 함께 장착할 수 없으며, 하나를 고르면 다른 하나의 자리를 차지합니다. 둘 다 당문암기총강 최대 레벨에서 열립니다.
  - 점수비석: 평사가 맞으면 가까운 다른 적에게 최대 3번 튕기며, 튕길 때마다 피해가 절반이 됩니다. 척석문천 최대 레벨에서 열립니다.
  
</details>

<details>
<summary><b>패시브</b></summary>

준비 화면 우측 상단에 표시되며, 전투가 시작되면 사라집니다. 목록이 길면 마우스 휠로 스크롤합니다.

- **삽답유성검**: 연격이 0일 때 다음 평타의 피해가 세 배가 됩니다.
- **사상전**: 전투를 연격이 쌓인 채로 시작합니다. 레벨이 높을수록 많이 쌓입니다.
- **서여림**: 기력이 회복될 때 더 많이 회복됩니다. 기능 「전술」 레벨에 비례합니다.
- **사초침**: 던진 암기가 맞으면 30% 확률로 상대의 균형을 잃게 합니다.
- **동여뢰진**: 운소뇌정벽력도에 맞은 적이 넘어져 2초간 움직이지 못합니다.
- **추가·암기**: 평사를 던질 때마다 하나 더 던집니다.
- **독공**: 근접 평타가 맞으면 평사 암기가 주는 중독·마비 누적치의 50%를 부여합니다(암기에 독·마비 효과가 있을 때).
- **의술**: 전투 중 10초마다 레벨의 2배만큼 체력을 회복합니다(최대 7레벨이면 14).
- **질여풍**: 달리기 속도가 「전술」 레벨당 2% 늘어납니다.
- **무영조**: 치명타 확률이 10%p 오릅니다.
- **점혈**: 근접 공격이 맞으면 레벨 × 4의 마비를 쌓습니다.
- **축랑결**: 근접 공격이 맞을 때 연격 × (레벨 × 3%) 확률(최대 50%)로 적이 균형을 잃습니다.
- **철포삼**: 최대 체력 100당 레벨 × 0.2%만큼 받는 피해가 줄어듭니다(최대 25%).
- **부동여산**: 받는 피해가 「전술」 레벨당 1.5% 줄어듭니다. 철포삼과 합쳐 최대 40%입니다.
- **침략여화**: 주는 피해가 「전술」 레벨당 2% 늘어납니다.

</details>

<details>
<summary><b>아군 스킬</b></summary>

준비 화면에서 스킬 버튼으로 장착해 부르는 동료들의 기술입니다.

- **대사형**: 하늘에서 내려와 돌면서 단검을 던지고, 폭탄을 떨어뜨린 뒤 떠납니다.
- **이사형**: 독약병을 던져 독을 남깁니다.
- **사사형**: 필드의 동전을 모아 던지고 회복약을 떨어뜨립니다.
- **소사매**: 분신들이 적에게 순간 돌진해 단검으로 베고, 마무리로 꿰뚫고 지나갑니다.
- **엽운주**: 가로로 대시하며 여섯 번 베는 장검 기술입니다. 동주검법을 익히면 이 스킬이 바뀝니다: 엽운주와 함께 적 무리 한가운데로 돌진해 모습을 감추고, 그곳에서 2초 동안 16번의 범위 베기 폭풍(반경 8 m, 최대 20명)을 일으킨 뒤 들어간 반대 방향으로 미끄러지며 나타납니다. 시전 중 조활은 조작할 수 없고 피해를 받지 않습니다.
- **용상**: 하늘에서 내려와 무작위 적에게 두 번 돌진해 벱니다.
- **상관형**: 금전표를 날리고 장검으로 베어 냅니다.
- **옥죽**: 무기를 던지거나 수레를 불러 적을 쓸어 냅니다.

</details>

<details>
<summary><b>설정 파일</b></summary>

`BepInEx\config\mortal.battle3d.cfg` — 게임을 한 번 실행하면 생성됩니다. 게임을 종료한 상태에서 메모장 등으로 수정하십시오.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `[General] Enabled` | `true` | 3D 전투 사용 여부 (끄면 모든 전투가 원본). F4 패널에서도 켜고 끌 수 있습니다. |
| `[General] ExcludedBattles` | `""` | 원본 2D 전투로 남길 전투 코드 (`BL_` 제외, 쉼표로 구분). 나머지 전투는 모두 3D입니다. 예: `1000,0001` |
| `[Controls] Scheme` | `Mouse` | 조작 방식: `Mouse` / `ClickMove` / `Keyboard` |
| `[Controls] AutoAim` | `true` | 적 자동 조준 (전투 중 왼쪽 Ctrl로도 전환) |
| `[Controls] SkillRelease` | `false` | 스킬을 키를 뗄 때 사용 (누르는 동안 사거리 표시). F4 패널에서도 전환할 수 있습니다. |
| `[Skills] Slot1Key ~ Slot4Key` | `q, e, r, f` | 스킬 슬롯 1~4의 키 (Input System 키 이름) |
| `[Skills] RememberLoadout` | `true` | 조활의 스킬 장착을 다음 전투에도 유지 |
| `[Camera] Pitch` | `35` | 카메라 기울기 (도) |
| `[Camera] Yaw` | `45` | 카메라 회전 (도) |
| `[Camera] Distance` | `23` | 기본 카메라 거리 (마우스 휠로 확대·축소) |
| `[Camera] ShakeStrength` | `0` | 화면 흔들림 세기 (0 = 끔, 1 = 기본) |
| `[Graphics] PostProcessing` | `true` | 블룸·색 보정·비네트 |
| `[Graphics] Intro` | `true` | 전투 입장 시 하늘에서 구름을 뚫고 내려오는 연출 |
| `[Graphics] ToonShader` | `true` | 툰 셰이딩 (끄면 일반 URP 셰이딩) |
| `[Graphics] Outline` | `true` | 캐릭터·무기 외곽선 |
| `[Sound] CustomVolume` | `1` | 모드 효과음(Audio 폴더) 음량 (0~1) |
| `[Sound] BasicSwingVolume` | `0.7` | 조활 기본 공격 휘두르는 소리의 추가 음량 배율 (0~1) |
| `[Diagnostics] DevelopmentMode` | `false` | 개발자용. 켜면 프레임 시간·메모리 기록을 `BepInEx\Battle3D_Performance`에 남깁니다(일반 사용자는 끄십시오). |

</details>

## 문제 해결
먼저 `BepInEx\LogOutput.log` 를 열어 확인하십시오. 모드가 정상적으로 실행되면 `[Battle 3D]` 로 시작하는 줄이 기록됩니다. 문제를 문의하실 때는 이 파일을 함께 첨부해 주십시오.

<details>
<summary><b>게임을 실행해도 모드가 켜지지 않습니다 (로그에 <code>[Battle 3D]</code> 줄이 없음)</b></summary>

- `BepInEx\LogOutput.log` 파일 자체가 없다면 BepInEx가 실행되지 않은 것입니다. 게임 폴더(`Mortal.exe` 옆)에 `winhttp.dll`, `doorstop_config.ini`, `BepInEx` 폴더가 있는지 확인하십시오. (설치 1, 2번을 다시 진행해 보십시오.)
- 파일 위치를 확인하십시오. 다음 네 항목이 모두 `BepInEx\plugins\Battle3D\` 안에 있어야 합니다: `Battle3D.dll`, `battle3d.bundle`, `battle3d_environment.bundle`, `Audio` 폴더. 폴더가 한 단계 더 들어가 있으면(`Battle3D\Battle3D\...`) 인식되지 않습니다.
- BepInEx는 **6.0.0-be.692 (Unity Mono)** 이어야 합니다. 5.x 버전이나 IL2CPP 빌드에서는 동작하지 않습니다.
- 다른 모드를 모두 `BepInEx\plugins`에서 잠시 제외하고 이 모드만 실행해 보십시오. 단독으로는 정상이지만 다른 모드와 함께 쓸 때 문제가 생긴다면, 함께 사용한 모드를 알려 주십시오.
- 압축 해제 시 윈도우가 파일을 차단하는 경우가 있습니다. zip 파일 속성에서 *차단 해제*를 체크한 뒤 다시 압축을 해제하십시오. 백신 프로그램이 `Battle3D.dll`을 격리하지 않았는지도 확인하십시오.

</details>

<details>
<summary><b>모드는 실행되지만 전투가 3D로 전환되지 않습니다</b></summary>

- `F4` 설정 패널에서 3D 전투가 켜져 있는지 확인하십시오. 설정 파일(`BepInEx\config\mortal.battle3d.cfg`)의 `[General] Enabled` 와 `ExcludedBattles` 도 확인하십시오.
- 아직 3D로 제작되지 않은 전투는 원본 그대로 진행됩니다.
- 로그에 `Battle 3D` 와 함께 오류(`Exception`)가 기록되어 있다면 해당 줄을 알려 주십시오.

</details>

<details>
<summary><b><code>file ... is corrupted! Position out of bounds</code> 와 같은 오류가 표시되며 게임이 종료됩니다</b></summary>

- `battle3d.bundle` 또는 `battle3d_environment.bundle` 이 완전히 내려받아지지 않았거나, 게임이 실행 중인 상태에서 덮어쓰기가 이루어진 경우 발생합니다. 게임을 완전히 종료한 뒤 zip을 다시 내려받아 덮어쓰십시오. (번들 두 개의 크기는 각각 약 70 MB, 56 MB입니다.)

</details>

<details>
<summary><b>설정을 초기화하고 싶습니다</b></summary>

- 게임을 종료한 뒤 `BepInEx\config\mortal.battle3d.cfg` 를 삭제하십시오. 다음 실행 시 기본값으로 다시 생성됩니다.

</details>

<details>
<summary><b>게임 업데이트 이후 오류가 발생합니다</b></summary>

- 게임 업데이트로 원본 코드가 변경되면 모드가 맞지 않을 수 있습니다. 최신 릴리즈가 있는지 확인하시고, 없다면 로그와 함께 Issues에 문의해 주십시오.

</details>
